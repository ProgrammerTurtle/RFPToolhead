## RFP Toolhead is my custom high performance ender 3 (or generic cartesian) toolhead. It is based around: 
- An SLM Aluminum Monobody part cooling duct/heatsink/mounting piece
- A custom supervolcano-length hotend optimized for weight savings and ideal mounting
- An Orbiter 1.5 extruder
- A BTT Eddy Duo scanning Z probe

This toolhead was speed-designed in only two days for HackClub Rework.
